# Jada - AI Friend Features

## 1-on-1 Chat (6 features)

1. **Gen Z Responses** - Casual, Gen Z style responses (2-4 messages, every 2-3 messages)
2. **Interest Extraction** - Tracks user interests automatically
3. **Music Recommendations** - Shares Taylor Swift songs when music is mentioned
4. **Voice Transcription** - Transcribes voice messages using Whisper AI
5. **Group Matching** - Creates/joins groups based on shared interests
6. **Conversation History** - Maintains context (up to 1000 tokens)

---

## Group Chat (18 features)

### User-Triggered (11 tools)

1. **Vibe Check** - "vibe check" → Analyzes group energy
2. **Aura Reading** - "aura" → Creative aura reading
3. **Get Lore** - "what's the lore" → Retrieves stored history
4. **Generate Catchup** - "catch me up" → Summary for users who were away
5. **Pin Core Memory** - "pin this" → Saves important moments
6. **Would You Rather** - "wyr" → Generates WYR questions
7. **Roast** - "roast [name]" → Playful roasts
8. **Hype Train** - "hype [name]" → Celebrates group members
9. **Story Mode** - "story mode" → Collaborative storytelling
10. **Show Achievements** - "achievements" → Displays group achievements
11. **Group Trivia** - "trivia" → Trivia questions

### Auto-Triggered (7 tools)

12. **Auto Vibe Check** - Checks vibe when chat is dead (30+ min)
13. **Ghost Detection** - Detects inactive members
14. **Temperature Check** - Detects tension/conflicts
15. **Auto Hype** - Auto-celebrates achievements
16. **Story Continuation** - Continues stories when story mode is active
17. **Suggest Tone Indicator** - Suggests tone indicators for ambiguous messages
18. **Generate Voice TLDR** - Summarizes long voice messages

---

## Key Features

- **Smart Responses**: Responds every 2-3 messages, only when necessary
- **LLM-Based**: Understands intent, not just keywords
- **Music**: Only when explicitly mentioned (22 Taylor Swift songs)
- **Group Matching**: Auto-creates/joins groups based on interests
